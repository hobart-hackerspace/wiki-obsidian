Our security systems are able to send notifications of signifiant events to designated Committee members. This is so that we can know about it and do something if things go wrong.

Notifications are sent using the [*Pushover*](https://pushover.net/) notification system. Committee members who want or need to receive notifications need to set up to receive them.

## Setting up *Pushover*
To receive notifications, you need to do three things:

1. Install the app or register on the website
	- Note that it will require a once-off payment of a small fee. 
2. Get a *Pushover* key
3. Register that key with our *Pushover* profile

### Installing or registering
- There are apps available from the relevant App stores for both Android & iOS.
	- Download the app and follow the registration process.
- If you prefer to receive notifications on a desktop or laptop, you can register on their website: [pushover.net/signup](https://pushover.net/signup).
- You can run for 30 days on the free trial registration; past that you need to pay the once-off small fee of $US5.00. The Space will reimburse you for this if you like.
	- There’s a separate fee for each generic platform (Android, iOS & web page). You can have multiple different devices of the same platform for one charge; if you want for example to receive on both phone & web page you need to pay for two platforms.

### Pushover key
- on the settings screen of the app or the landing page for web users there’s an alphanumeric ***User Key***.
- Copy this and:
	- provide it to one of the other folks managing notifications (email to pushover@hobarthackerspace.org.au)  or
	- add it yourself to our profile as described next.

### Registering your key
Our Pushover account is managed by logging in to Pushover as pushover@hobarthackerspace.org.au. The password for this is in our [password vault](Governance/Password%20vault.md).

- Log into that account
- It shows a list of *Delivery Groups*. Click on *Hackerspace recipients*.
- Add your *User key* to the list.
